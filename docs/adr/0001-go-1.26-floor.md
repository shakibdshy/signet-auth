# Go 1.26 floor

Signet targets Go 1.26 even though the original brief asked for a 1.22 floor. Go supports only its two most recent major releases: 1.22 stopped receiving fixes when 1.25 shipped, while 1.26 and 1.27 are supported today. Shipping a security library on an unsupported toolchain would push that cost onto every application embedding it. The enhanced `net/http` routing patterns are used only in examples, never in the router-agnostic core.
