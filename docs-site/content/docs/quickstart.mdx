## Install

```bash
go get github.com/shakibdshy/signet
```

## Configure a Client

A `Store`, `Mailer`, `RateLimiter` and 32-byte CSRF key are required. Bundled
adapters live in `store/sqlite`, `store/postgres` and `mailer/console` (development
only).

```go
cfg := signet.DefaultConfig()
cfg.Store = myStore
cfg.Mailer = console.New(os.Stdout)
cfg.RateLimiter = myLimiter
cfg.CSRFKey = key // 32 random bytes
cfg.AppURL = "https://app.example.com"

auth, err := signet.New(cfg)
if err != nil {
    log.Fatal(err)
}
```

`DefaultConfig()` supplies secure defaults for cookies, sessions and passwords.
Insecure options are named `Insecure*` and emit warnings when used.

Every field, default and pointer-semantics rule is listed in the [Configuration](/docs/configuration) reference; failures are mapped in [Errors](/docs/errors).

## Use the programmatic API

```go
_, err := auth.SignUp(ctx, signet.SignUpInput{
    Email: "user@example.com", Password: "correct horse battery staple",
})
result, err := auth.SignIn(ctx, signet.SignInInput{
    Email: "user@example.com", Password: "correct horse battery staple",
})
```

## Or mount the HTTP API

```go
mux.Handle("/auth/", http.StripPrefix("/auth", auth.Handler()))
```

This exposes `/signup`, `/signin`, `/signout`, `/sessions`, `/session`, `/token`,
`/csrf-token` and the verification, reset and OAuth endpoints under your prefix.
State-changing requests require a signed CSRF token — see [Sessions and cookies](/docs/sessions).

<Callout title="Development only">
`mailer/console` prints messages instead of sending them. Use `mailer/smtp` in
production; STARTTLS is the default.
</Callout>

## Sign out

```go
if err := auth.SignOut(ctx, signet.SignOutInput{SessionToken: result.SessionToken}); err != nil {
    log.Fatal(err)
}
```

The HTTP equivalent is `POST /signout`, which also clears the session cookie.

## Runnable examples

Five separate Go modules show the same API with different routers: `examples/stdlib`,
`examples/chi`, `examples/echo`, `examples/gin` and `examples/fiber`. Each uses a
PostgreSQL database, defaulting to
`postgres://signet:signet@localhost:5432/signet?sslmode=disable`; override it with
`SIGNET_DATABASE_URL`. They call `Migrate(ctx)` at startup, use the console mailer and an
in-memory limiter, mount auth under `/auth`, and disable email verification for local
convenience. Copy one as the starting point for your application.

<Callout title="JWT-only applications">
`Config.JWTOnly` skips session cookies, so no `CSRFKey` is required. See [JWT](/docs/jwt).
</Callout>
