---
title: SCIM provisioning
description: Provision Users and Groups from a corporate directory, with group-to-role projection.
---

Follow these steps to connect a directory to Signet. SCIM handles provisioning only — sign-in is covered by [Organization SSO](/docs/organization-sso) or [SAML SSO](/docs/saml).

## 1. Implement the optional store

```go
type directoryStore struct {
    mu       sync.Mutex
    users    map[string]*signet.User
    external map[string]string
    groups   map[string]*signet.SCIMGroup
}

func (s *directoryStore) UserByExternalID(ctx context.Context, externalID string) (*signet.User, error) {
    s.mu.Lock()
    defer s.mu.Unlock()
    user := s.users[s.external[externalID]]
    if user == nil {
        return nil, signet.ErrNotFound
    }
    return user, nil
}

func (s *directoryStore) SetUserExternalID(_ context.Context, userID, externalID string) error {
    s.mu.Lock()
    defer s.mu.Unlock()
    s.external[externalID] = userID
    return nil
}

func (s *directoryStore) ExternalIDByUser(_ context.Context, userID string) (string, error) {
    s.mu.Lock()
    defer s.mu.Unlock()
    for external, id := range s.external {
        if id == userID {
            return external, nil
        }
    }
    return "", signet.ErrNotFound
}

func (s *directoryStore) ListUsers(context.Context) ([]*signet.User, error) { /* return all Users */ }
func (s *directoryStore) GroupByExternalID(_ context.Context, externalID string) (*signet.SCIMGroup, error) {
    /* find by ExternalID */
}
func (s *directoryStore) GroupByID(_ context.Context, id string) (*signet.SCIMGroup, error) {
    /* find by ID */
}
func (s *directoryStore) CreateGroup(_ context.Context, group *signet.SCIMGroup) error {
    /* persist group */
}
func (s *directoryStore) UpdateGroup(_ context.Context, group *signet.SCIMGroup) error {
    /* replace group */
}
func (s *directoryStore) DeleteGroup(_ context.Context, id string) error {
    /* remove group */
}
func (s *directoryStore) ListGroups(context.Context) ([]*signet.SCIMGroup, error) { /* return all Groups */ }
```

## 2. Configure SCIM

```go
cfg := signet.DefaultConfig()
cfg.Store = myStore
cfg.Mailer = myMailer
cfg.RateLimiter = myLimiter

cfg.SCIM = &signet.SCIMConfig{
    Store: myDirectoryStore,
    Token: os.Getenv("SCIM_BEARER_TOKEN"),
    Projector: func(ctx context.Context, group *signet.SCIMGroup) error {
        // Your application decides which Organization and role the group maps to.
        return myRoles.Project(ctx, group.ID, group.DisplayName, group.Members)
    },
}

auth, err := signet.New(cfg)
if err != nil {
    panic(err) // ErrInvalidSCIMConfig when Store or Token is missing
}
```

The token is compared in constant time. Both `Store` and `Token` are required.

## 3. Mount the SCIM handler

Signet's main `Handler()` serves SCIM under your configured `PathPrefix`:

```go
// With PathPrefix "/auth" the SCIM endpoints live at /auth/scim/Users and /auth/scim/Groups.
http.Handle("/auth/", http.StripPrefix("/auth", auth.Handler()))
```

## 4. Provision a User from the directory

The directory sends a standard SCIM request:

```bash
curl -X POST https://api.example.com/auth/scim/Users \
  -H "Authorization: Bearer $SCIM_BEARER_TOKEN" \
  -H 'Content-Type: application/scim+json' \
  -d '{
    "schemas": ["urn:ietf:params:scim:schemas:core:2.0:User"],
    "userName": "alice@acme.com",
    "externalId": "directory-user-42"
  }'
```

The response contains the Signet User ID. Signet records the external ID mapping in your `SCIMStore`.

## 5. Deactivate a User

```bash
curl -X PATCH https://api.example.com/auth/scim/Users/USER_ID \
  -H "Authorization: Bearer $SCIM_BEARER_TOKEN" \
  -H 'Content-Type: application/scim+json' \
  -d '{
    "schemas": ["urn:ietf:params:scim:api:messages:2.0:PatchOp"],
    "Operations": [{"op": "replace", "path": "active", "value": false}]
  }'
```

This sets `User.Disabled = true`. Deleting the User through `DELETE` also revokes Sessions, Tokens and Accounts.

## 6. Sync a Group and project roles

```bash
curl -X POST https://api.example.com/auth/scim/Groups \
  -H "Authorization: Bearer $SCIM_BEARER_TOKEN" \
  -H 'Content-Type: application/scim+json' \
  -d '{
    "schemas": ["urn:ietf:params:scim:schemas:core:2.0:Group"],
    "displayName": "acme-admins",
    "externalId": "directory-group-7",
    "members": [{"value": "USER_ID"}]
  }'
```

`Projector` runs before the group is stored, so a projection failure never leaves a partially provisioned group. The same projection runs on `PATCH` and `REPLACE`.

## 7. Verify

```bash
curl -H "Authorization: Bearer $SCIM_BEARER_TOKEN" \
  https://api.example.com/auth/scim/Users
```

Every mutation emits an Audit event (`scim_user_created`, `scim_user_updated`, `scim_group_created`, and so on) through the configured sink. Schema-discovery endpoints are intentionally disabled.
