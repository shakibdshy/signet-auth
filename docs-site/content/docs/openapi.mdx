For a prose map of all endpoints and their requirements, see the [HTTP API](/docs/http-api) page.

The reference below is generated from `api/signet.openapi.json`, which Signet
produces from the same declarative contract that drives its HTTP handlers. Each
page shows the request body, responses, status codes and error codes, with an
interactive playground. Endpoints are grouped into accordions by area (Authentication,
Sessions, Passkeys, Admin users, and so on) so related operations sit together.
